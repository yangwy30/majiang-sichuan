# majiang-sichuan

四川麻将（血战到底 / 血流成河）拍照算番、查大叫与刮风下雨记账 iOS App。

专为线下川麻打造：支持局内多次胡牌、一键记录刮风（明杠/巴杠）与下雨（暗杠）、杠上炮「呼叫转移」、流局自动「退税」（未下叫退还全局杠钱），以及拍照识别 14 张胡牌算番或 13 张未胡手牌自动「查花猪 / 查大叫」（穷举最大听牌番数），打完一键算出最少转账笔数与微信战报图。

## 目录结构

- `app/MajiangKit`：纯 Swift 核心库（108 张万筒条牌面、端侧 + Gemini 双读管线、川麻番型与根数计算引擎、13 张听牌最大番「查大叫」求解器、支持刮风下雨/退税/呼叫转移的局内多事件账本）
- `app/MajiangApp`：SwiftUI iOS 客户端（局内极速记杠/记胡面板、拍照算番与拍照查大叫、家规配置、牌桌方桌与微信账本分享图）
